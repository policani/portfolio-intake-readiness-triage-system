# Trigger Map

## Use this module when

- Demand is new, rough, vague, solution-first, or sponsor-unclear.
- A leader needs to know what route the request belongs in.
- A request may be important but is not ready for business case, charter, or scoring.
- Multiple intake items need consistent classification.

## Do not use this module when

- The user already needs a finished business case.
- The user already needs a full charter.
- The user is scoring approved portfolio investments.
- The user is logging active PMO operating notes.
- The user is reviewing an existing AI artifact.

## Route instead

| Input type | Better destination |
|---|---|
| Rough AI opportunity | AI Opportunity Intelligence Review System |
| Existing AI tool/script/dashboard/agent concern | AI Artifact Lifecycle Governance System |
| Investment decision artifact needed | Business Case System |
| Approved intent needs initiation structure | Project Charter Initiation Agent |
| Approved candidate needs comparative scoring | Portfolio Prioritization Scoring Agent |
| Active meeting/status/escalation notes | PMO Governance Operations Log |
