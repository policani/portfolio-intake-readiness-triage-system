# Handoff Rules

## Handoff packet contents

Every routed item should include:

- Intake record
- Classification
- Readiness score
- Rationale
- Sponsor status
- Missing evidence
- Dependency and capacity flags
- Assumptions
- Human decisions required
- Items explicitly excluded from the handoff

## Business Case System handoff

Include value hypothesis, options needed, evidence gaps, assumptions, cost/benefit unknowns, decision audience, and sponsor.

## Project Charter Initiation Agent handoff

Include approved intent, scope clues, objectives, sponsor, impacted teams, known constraints, assumptions, risks, dependencies, and governance needs.

## Portfolio Prioritization Scoring Agent handoff

Include candidate summary, strategic theme, sponsor, constraints, urgency driver, capacity signal, dependencies, and reason it is ready for comparative scoring.

## AI Opportunity Intelligence Review System handoff

Include AI idea, use case, user population, expected work reduction or decision improvement, data sensitivity, build/buy/wait question, and proof needed.

## AI Artifact Lifecycle Governance System handoff

Include existing artifact description, users, reliance level, business process touched, data exposure, owner, and disposition concern.

## PMO Governance Operations Log handoff

Include operating note, decision, blocker, action, owner, due date, escalation, and carry-forward topic.
