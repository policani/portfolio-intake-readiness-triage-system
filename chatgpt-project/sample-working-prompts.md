# Sample Working Prompts

## Single item triage

Triage this portfolio intake item. Classify it as reject, hold, clarify, business case, charter, or portfolio scoring candidate. Show the readiness score, sponsorship gaps, missing evidence, dependency/capacity flags, and recommended handoff.

## Batch triage

Triage these intake items as a batch. Use the same scoring method for each. Return a comparison table first, then a detailed record for each item.

## Sponsor gap review

Review this request only for sponsorship readiness. Identify whether the sponsor is clear, whether decision rights are known, and what must be confirmed before routing.

## Problem clarity review

Challenge the problem framing in this request. Separate facts, assumptions, proposed solutions, and missing evidence. Provide a cleaner problem statement if possible.

## Route-only pass

Do a fast route-only pass. Use best-effort assumptions, show confidence, and list the top three things that would change the classification.

## Public-safe example conversion

Convert this intake example into a public-safe synthetic version. Remove or generalize employer, client, financial, security, system, customer, and personal details.
