# Operating Model

## Purpose

Create a lightweight intake readiness layer for portfolio demand before it becomes false work-in-progress, premature planning, or executive noise.

## Starts when

A request, idea, mandate, initiative, project, AI use case, compliance need, or executive ask enters the portfolio funnel.

## Ends when

The item has an intake readiness classification and a routing recommendation.

## Produces

- Intake record
- Readiness score
- Sponsorship gaps
- Missing evidence list
- Dependency and capacity flags
- Route recommendation
- Handoff packet

## Hands off to

- Business Case System
- Project Charter Initiation Agent
- Portfolio Prioritization Scoring Agent
- AI Opportunity Intelligence Review System
- AI Artifact Lifecycle Governance System
- PMO Governance Operations Log

## Does not

- Build the business case
- Write the charter
- Score approved investments
- Authorize execution
- Commit funding or capacity
- Accept risk
- Notify stakeholders
- Change systems of record
