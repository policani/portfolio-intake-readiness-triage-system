# Start Here

Use this runtime when a request, idea, mandate, initiative, AI use case, compliance need, or executive ask enters the portfolio funnel and needs triage before business case, charter, or scoring work.

## Session path

1. Capture the request using `intake-record-template.md`.
2. Confirm whether this system applies using `trigger-map.md`.
3. Screen sponsorship, problem clarity, dependencies, and capacity.
4. Score readiness using `readiness-triage-rules.md`.
5. Select a route using `routing-rules.md`.
6. Produce the final output using `output-templates.md`.
7. Prepare downstream handoff using `handoff-rules.md`.
8. Review with `quality-review-rubric.md` before finalizing.

## Default user prompt

Paste the request or intake notes and ask:

`Triage this portfolio intake item. Classify it as reject, hold, clarify, business case, charter, or portfolio scoring candidate. Show the readiness score, gaps, and recommended handoff.`

## Boundary

This module produces readiness classification and routing. It does not authorize execution or create the downstream artifact.
