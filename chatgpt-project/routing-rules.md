# Routing Rules

## Reject

Use when the item has no plausible business problem, is outside remit, duplicates existing work without new evidence, requests inappropriate action, or lacks any credible path to ownership.

## Hold

Use when the item may become valid later but lacks a trigger, sponsor, capacity path, budget path, or external decision.

## Clarify

Use when the item has enough signal to investigate but lacks core routing information.

## Business case

Use when the problem and sponsor are credible but the item needs value logic, options, assumptions, costs, benefits, risks, or executive decision framing.

## Charter

Use when intent is approved or mandated and the next need is project definition, scope, ownership, governance rhythm, risks, dependencies, and planning handoff.

## Portfolio scoring candidate

Use when the item is approved enough to compare against other portfolio candidates for priority, sequence, constraints, capacity, and tradeoffs.

## Special routes

- Rough AI opportunity: AI Opportunity Intelligence Review System
- Existing AI artifact concern: AI Artifact Lifecycle Governance System
- Active governance note or escalation: PMO Governance Operations Log
